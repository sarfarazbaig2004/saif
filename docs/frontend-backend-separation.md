# Aman Infra ERP Separation Rule

## Frontend
Flutter Web application.
Location: lib/

Contains:
- Screens
- Widgets
- Forms
- Tables
- Navigation
- Providers
- UI state

## Backend
Firebase Cloud Functions.
Location: functions/

Contains:
- OTP
- Authentication workflows
- User creation
- Approval workflows
- Auto numbering
- Stock posting
- Financial calculations
- Audit logs
- Server validation

## Database
Firestore collections, rules, indexes.

Files:
- firestore.rules
- firestore.indexes.json

## Principle

Frontend asks.
Backend decides.
Firestore stores.
Rules protect.
